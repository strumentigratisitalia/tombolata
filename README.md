# Tombolata

La tombola di Natale sul telefono di tutti: un dispositivo fa da tabellone ed estrae i numeri con la smorfia napoletana (anche a voce), gli altri prendono le cartelle sul proprio telefono. Il sito avvisa per ambo, terno, quaterna, cinquina e tombola. Gratis, senza app né registrazione, anche in videochiamata.

Sito: https://strumentigratisitalia.github.io/tombolata/

## Come funziona

Ogni cartella è generata dal suo numero, così chi tiene il tabellone può verificare una vincita rigenerando la stessa cartella. Nessun server: tutto gira nel browser.

HTML, CSS e JavaScript puri, nessun build. Libreria QR: qrcode-generator di Kazuhiko Arase (MIT). Segnalazioni e correzioni sono benvenute nelle issue.
